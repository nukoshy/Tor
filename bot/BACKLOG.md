## ✅ Сделано
- Каркас: WAHA-шлюз, «сначала человек — потом бот», склейка сообщений, вебхук с токеном.
- Полный сценарий брони: залы/караоке, лимит месяц, эскалации менеджеру, номера заявок #N.
- Язык: зеркалирование ru/kk + транслит, принудительный перевод при промахе.
- Стиль «как человек»: чек-лист первого ответа, поздравления/соболезнования, живой казахский.
- Команды: владелец `!бот` / `!стоп` / `!ок N`; клиент `!стоп` / `!бот` с подтверждениями.
- Журнал заявок (переживает рестарты) + утренний дайджест 09:00 + напоминание через 3 часа.
- Мониторинг WhatsApp-сессии (алерт при восстановлении, статус в /health).
- Телефон для @lid-чатов: бот спрашивает номер, если WhatsApp скрыл его.
- Ссылка на онлайн-меню и праздники Казахстана в базе знаний.
- Починены: двойная доставка событий, @lid-чаты, эхо-петля «[менеджер]:», утечка чужих броней.
- Батарея из 32 живых сценариев (`npm run bakeoff`, `node scripts/scenarios.js`), 70+ автотестов.
